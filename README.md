# The PYQ Project — Free UPSC CSE Prelims PYQ Practice & Mock Tests

A high-fidelity dark-mode web platform for UPSC Civil Services Examination aspirants to practice Previous Year Questions (PYQs) and timed Mock Tests with full **Hindi Language** and **English** support.

Designed with reference to [pyq-project.in](https://pyq-project.in) using exact measured typography, dark theme color tokens, and interactive components.

## Features

- **Hindi Medium Engine (`हिन्दी माध्यम`):** Complete bilingual and Hindi mock test simulation with authentic UPSC phrasing.
- **Prelims Marking Scheme:** Real-time scoring with +2.00 marks for correct answers and -0.66 negative marking.
- **Question Palette & Timer:** 2-hour countdown timer, flag for review, and colored status navigation.
- **Subject Coverage:** Polity, Economy, Environment & Ecology, History & Culture, Geography, Science & Technology, and CSAT Paper II.
- **Zero-Dependency:** Instant launch via static HTML or Node.js server.
- **Automated GitHub Pages Deployment:** Built-in GitHub Actions workflow to publish live automatically.

## Local Quick Start

Run locally with Node.js:
```bash
node server.js
```
Then visit `http://localhost:3000`.

Or open `index.html` directly in your browser.
